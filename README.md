# 风华正茂 · 论坛版 Demo（Discourse 风格）

参照 [Discourse](https://www.discourse.org/)（GPL-2.0 开源论坛）的布局与交互做的纪念站原型：
左侧分类/标签栏、居中搜索、话题列表、楼层式回帖、深色主题（可切浅色）。
仅借鉴结构与风格，未使用其代码与品牌素材；数据仍是「风华正茂」纪念站内容。

## 打开方式

- 双击 `index.html`，或
- `python -m http.server 8123 --directory "E:/code/dmsyzx-forum"` 后访问 <http://127.0.0.1:8123>

## 与 Discourse 的对应关系

| Discourse | 本站 |
|---|---|
| Categories 分类 | 年级（2018/2019/2020 级，彩色徽章） |
| Topics 话题 | 同学故事 |
| Posts 楼层回帖 | 评论（@某人、点赞、#楼层号） |
| Tags 标签 | 军训、运动会、毕业照…… |

## 已实现

- **进入页**：「当时只道是寻常」全屏封面，点击进入后本会话内不再重复（换浏览器会话会再次出现）
- 最新 / 热门排序，分类、标签、全文搜索三重筛选
- 置顶话题（📌 永远在列表最前）
- 话题详情：楼主徽章、楼层号、@回应、每楼点赞（可切换）
- 创建话题（标题 + 年级分类 + 标签 + 正文，弹窗表单）
- 点赞 / 回帖 / 新话题保存在本机浏览器（localStorage），刷新不丢
- 深色 / 浅色主题切换（记忆选择）；移动端抽屉式侧栏

## 文件结构

```
dmsyzx-forum/
├── index.html       话题列表页（含进入页）
├── topic.html       话题详情页
├── css/style.css    Discourse 风格深色主题
├── js/data.js       演示数据（3 分类 / 9 话题）
├── js/app.js        渲染与交互
└── assets/*.svg     手绘风插画（正文配图）+ 进入页背景 cover.svg
```

## 从 Demo 到正式版

正式版将把 localStorage 换成数据库（多用户、邀请码注册、审核），
交互与页面结构基本可以沿用本原型。
