# 风华正茂 · 高中同学故事纪念站

按年级组织的高中同学社区：发帖（图文）、#话题、楼中楼评论、私信、收藏、关注。
界面借鉴 [Discourse](https://www.discourse.org/) 的三栏结构与 [bbs-go](https://github.com/mlogclub/bbs-go)（GPL-3.0）的卡片与配色风格，代码全部自研；进入页「当时只道是寻常」。

## 快速启动

```bash
npm install          # 首次
node server/server.js   # 或 npm start，默认端口 8123
```

访问 <http://127.0.0.1:8123>（静态页面双击打开仅可浏览，登录/发帖等需后端运行）。

## 页面一览

| 页面 | 地址 | 说明 |
|---|---|---|
| 广场（首页） | `index.html` | 三栏：左分类·年级/标签（热度 Top5 高亮）+ 中话题流（最新/热门）+ 右用户卡/站点统计 |
| 话题详情 | `topic.html?id=1` | 主楼卡片（作者/正文/图片/徽章 + 浏览·点赞·评论·收藏操作栏）、评论卡片（楼中楼、图片）、作者卡（关注/私信） |
| 发布帖子 | `post.html` | 标题 + `#话题` 输入（抖音式预选下拉/创建新话题）+ 正文（可空）+ 图片（9 张，自动压缩） |
| 登录/注册 | `login.html` | 独立页三模式：登录（昵称或邮箱）/ 注册 / 忘记密码（邮箱验证码） |
| 个人中心 | `me.html` | 我发布的 / 我的回复 / 我的收藏（失效收藏自动清理） |
| 私信 | `messages.html` | 会话列表 + 聊天窗；未互关时对方回复前仅可发一条，互关畅聊；支持图片 |
| 管理后台 | `admin.html` | 管理员登录；访问统计/14 天趋势、用户管理（搜索/编辑/重置密码/删除）、话题管理（置顶/删除）、年级分类管理 |

## 核心功能

- **账号**：邮箱验证码注册（QQ 邮箱 SMTP）、scrypt 密码、HttpOnly Cookie 会话；昵称或邮箱登录；头像颜色/昵称自助修改；更换邮箱（新邮箱验证码）；入学年级仅可自助修改一次
- **内容**：发帖自动归入发帖人年级（头衔）；年级分类 = 后台基础配置 ∪ 注册用户年级（如 2025 级同学注册后自动出现）；`#话题` 全站联动；浏览量按访客去重（一人一帖只 +1）
- **互动**：楼主徽章 + 年级头衔徽章；评论楼中楼（级联删除）；点赞/收藏/关注/私信
- **管理**：站点统计、用户增删改、话题置顶/删除（同步清理收藏）、默认密码 123456 可改的二次确认重置
- **主题**：深色（默认）/浅色，参考 bbs-go 配色，全站同步记忆；移动端抽屉式侧栏

## 目录结构

```
dmsyzx-forum/
├── index.html / topic.html / post.html / login.html / me.html / messages.html / admin.html
├── css/style.css        全站样式（两套主题变量）
├── js/                  前端逻辑（app=列表/话题页，auth=登录态/菜单，login/post/me/messages/admin 各自页面）
├── server/
│   ├── server.js        Express 后端（API + 静态托管 + 访问统计）
│   ├── mailer.js        QQ 邮箱 SMTP 发验证码
│   ├── store.js         JSON 文件数据库
│   ├── config.json      端口/SMTP/管理员凭据（敏感，勿公开）
│   └── data/            db.json 数据 + uploads/ 图片（git 忽略）
└── assets/*.svg         手绘风插画（内置示例话题配图）+ cover.svg 进入页背景
```

## 演示数据

内置示例话题在 `js/data.js`（2018/2019/2020 级各 3 篇，含示例评论）；正式版可整体迁入数据库。
新注册用户（如 2025 级）发帖后其年级分类自动生效。

## 运维备忘

- **改端口/邮箱授权码/管理员账号密码**：只改 `server/config.json`，重启生效（管理员凭据以配置为准）
- **备份**：拷贝 `server/data/` 目录即可（db.json + uploads）
- **版本管理**：本目录是 git 仓库，每次功能改动有 commit；回滚用 `git log` 找基线后 `git checkout <hash> -- .`
- **静态资源缓存**：HTML 引用带 `?v=N` 版本号，改动 JS/CSS 后需同步升版本（当前 v=47）

## Demo → 正式版路线

1. 数据库 JSON → SQLite（接口不变）
2. 内置示例话题迁入数据库、绑定真实账号
3. 部署：Node 常驻 + Nginx 反代 + HTTPS + 域名（国内需备案）
